# Langues de Cerclic

Cerclic parle 10 langues : français, anglais, espagnol, allemand, italien,
portugais (du Brésil), arabe (interface de droite à gauche), turc, chinois
simplifié, japonais. Il prend la langue de l'ordinateur (anglais si Cerclic ne
l'a pas) ; « Langue », dans Général, en choisit une autre, aussitôt.

## Dans le code

Le texte français écrit dans le code est la source : il s'affiche tel quel en
français et sert de clé aux catalogues `cerclic/locales/<code>.py`
(`T = {"texte français": "traduction"}`). Fonctions de `cerclic/i18n.py` :

| Écrire | Pour |
|---|---|
| `tr("Rogner")` | un texte |
| `tr("{name} est prêt", name=n)` | un texte avec des valeurs, champs nommés |
| `trn("{n} fichier", "{n} fichiers", n)` | un texte qui change avec un nombre |
| `trc("son", "Son")` | le même mot français avec un autre sens |
| `N_("Rogner")` | un texte gardé dans une constante ; traduit là où il s'affiche, `tr(valeur)` |

Règles :

1. **Tout ce que l'utilisateur lit** passe par ces fonctions : libellés, boutons,
   infobulles, messages, cartes, erreurs montrées, titres de fenêtres, menu de
   l'icône, noms des touches (Maj, Espace, Entrée, Suppr, Retour), unités de
   taille, suffixes des fichiers créés (« (compressé) »). Pas le journal
   (`log`), ni `--selftest`, ni les identifiants, clés de réglages, noms de
   fichiers internes.
2. **Jamais de f-string autour d'un texte à traduire** : `f"{name} est prêt"`
   devient `tr("{name} est prêt", name=name)`. Champs nommés, sans format
   (`{x:.1f}`) : préparer la valeur avant (`sizes.human`, `i18n.decimal`).
3. **Des phrases entières**, jamais une phrase faite de morceaux traduits à
   part (l'ordre des mots change d'une langue à l'autre). Ce qui diffère entre
   Mac et Windows s'écrit en deux phrases complètes :
   `tr("… dans le Finder") if IS_MAC else tr("… dans l'Explorateur")`.
4. **Pluriels** : `trn(...)`, jamais `"s" if n > 1`.
5. **Constantes** (calculées à l'import : actions, formats, niveaux, préréglages) :
   texte français marqué `N_()`, traduit là où il s'affiche (`tr(a.label)`). Les
   données restent en français, l'affichage traduit.
6. **Changer de langue sans redémarrer** : ce qui s'ouvre ensuite parle la
   nouvelle langue ; ce qui reste ouvert (menu de l'icône, fenêtre de Cerclic)
   se reconstruit par `i18n.on_change(...)`.
7. Les processus de travail (PDF lourds) reçoivent la langue de Cerclic.

Les tests tournent en français (`CERCLIC_LANG=fr`, dans `tests/conftest.py`).
`python scripts/i18n_messages.py` liste les textes trouvés dans le code ;
`--check` vérifie que chaque catalogue est complet et garde les mêmes champs.

## Pour traduire

- Un catalogue par langue, la clé est le texte français exact.
- Garder les champs `{...}` tels quels (on peut les déplacer dans la phrase).
- Pluriels : une liste de formes, 2 en général, 1 en chinois et japonais,
  6 en arabe (0, 1, 2, 3 à 10, 11 à 99, autres), comme `i18n.plural_index`.
- Les mots du système dans sa langue, tels qu'Apple et Microsoft les traduisent :
  Finder, Explorateur de fichiers, Actions rapides, Ouvrir avec, Réglages
  Système, Confidentialité et sécurité, « Ouvrir quand même », Afficher
  d'autres options, Applications, Téléchargements…
- Les touches comme sur les claviers du pays (en allemand, Ctrl s'écrit Strg).
- Ton : celui d'une app grand public, direct, comme Apple dans cette langue
  (tutoiement là où il est d'usage : du, tú, tu, você).
- Libellés de la roue courts (deux lignes au plus, une douzaine de signes par ligne).
- Cerclic, PDF, JPG, PNG, MP4, MP3, HEIC… ne se traduisent pas.
